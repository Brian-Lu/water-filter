3. The spot

  • Unfinished basement, concrete floor: 40" wide × 36" deep × 80" high (floor to overhead pipe run). Homeowner measurement, please confirm.
  • Row in line: three housings on one shared bracket (~25") + ~4" for union/valve + 9" resin tank ≈ 38" of the 40". Brine tank in front of the resin tank; UV horizontal above the pipe run.
  • If 38" won't go with real fittings, move the sediment housing upstream on the main (frees ~9").
  • Run the row in 1" (copper or PEX) even if the house line is 3/4"; full-port ball valves + unions both sides of each device, one bypass loop around the whole row.
  • Cartridges change from below: keep ≥5" clear under each housing bowl.

4. Confirm on the site visit

5. Install-day asks

  • Valves + unions on every device, bypass loop around the row, softener on its own bypass too.
  • Pressure test and leak check before leaving; flush carbon cartridges to drain per Pentair (fines).
  • Leak sensor with auto-shutoff valve on the main.
  • Label each valve (bypass, in, out) and the drain line.
  • Show the homeowner one cartridge change (bowl down, O-ring grease, burp air).
  • Softener set from a measured hardness/chlorine test on the day (~3–4 grains expected).
